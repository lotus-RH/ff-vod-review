Auto-Sync from YouTube (recommended — one-time setup)

Add a free YouTube Data API key here once, and every POV video you paste in afterward syncs itself automatically from that VOD's actual live broadcast start time — no manual timestamp entry, ever, as long as the video was streamed live on YouTube (not just uploaded). Do this once per browser, or save it into the shared setup file below so every viewer gets it automatically. Get one free at console.cloud.google.com → enable "YouTube Data API v3" → Credentials → Create API Key. Manual calibration (typing in one timestamp per video) is still available as a fallback for uploaded/edited videos.
